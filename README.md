## Sobre

Keyra é um aplicativo mobile construído com Dart/Flutter, com interface moderna e funcionalidades interativas. Demonstra domínio de Dart e construção de UI nativa multi-plataforma.

## Tech Stack

- **Dart** — Linguagem principal
- **Flutter** — Framework UI multi-plataforma

## Como Rodar

```bash
# Instalar dependências
flutter pub get

# Rodar em modo debug
flutter run

# Build para produção (Android)
flutter build apk
```
