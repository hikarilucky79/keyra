Arquitetura Híbrida de Alta Performance

O Keyra separa a interface da execução crítica. O daemon opera em segundo plano em Rust puro, consumindo menos de 10MB de RAM e mantendo latência inferior a 1ms, enquanto a UI interage via IPC seguro de forma assíncrona.

  • Rust Daemon: Monitoramento estável de keystrokes a nível do sistema operacional.
  • Comunicação IPC: Sockets de domínio Unix (Linux) e Named Pipes (Windows).
  • Teclado Virtual 60%: Visualizador interativo de teclas físicas no Flutter com efeito shockwave.
